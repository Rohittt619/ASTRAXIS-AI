# ASTRAXIS-AI Benchmark Specifications

## Performance Targets

- **Graph Traversal Time**: < 10ms for graphs up to 100 nodes.
- **Payload Generation Rate**: > 1,000 synthetic payloads/second.
- **Sandbox Fallback Switch**: < 5ms automatic fallback to synthetic runner.
- **Audit Hash Computation**: < 2ms for report dictionaries.
