# Cybersecurity & AI Safety Glossary

- **Red-Teaming**: Simulating real-world threat actors to find security flaws.
- **Prompt Injection**: Manipulating LLM instructions via untrusted text.
- **Tool Hijacking**: Forcing an AI agent to execute arbitrary parameters on system tools.
- **Agent Collusion**: Inter-agent message tampering to bypass guardrails.
- **Attack Graph**: Directed graph representation of system components and exploit vectors.
