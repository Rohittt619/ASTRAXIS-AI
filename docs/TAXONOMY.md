# ASTRAXIS-AI Multi-Agent Red-Teaming Threat Taxonomy Specification

## Threat Categories

1. **DIRECT_INJECTION**: Adversarial text directly embedded in user prompt input.
2. **INDIRECT_INJECTION**: Hidden instructions embedded in external documents, websites, or database records.
3. **JAILBREAK**: Roleplay framing or DAN-style prompts designed to bypass content filtering.
4. **OBFUSCATION**: Base64 or encoding tricks to bypass keyword filters.
5. **SYSTEM_OVERRIDE**: Instructions attempting to replace the system prompt.
